# 验证结果

Cv-MemoEngine 的结果不是单次吞吐峰值，而是经过正确性、稳定性和执行路径验证的交付结果。

## 正式服务验证

| 检查项 | 结果 |
| --- | --- |
| 并发档位 | 10 档：C1 至 C19 奇数档 |
| 正式轮次 | 每个档位 4 轮 |
| 正式 case | **40 / 40 成功** |
| 输出计数 | 实际输出 token 符合测试约束 |
| 错误状态 | 无失败、无跳过 |
| 基准结果 | C1 52.93 tokens/s；C19 88.47 tokens/s |

C19 是 4 轮成功结果的聚合值，不是单次最佳样本。

## 长序列验证

| 检查项 | 结果 |
| --- | --- |
| 并发数 | 1 |
| 成功长度点 | **83** |
| 每点重复次数 | 2 |
| 长序列运行总数 | **166** |
| 输入范围 | 100–17,700 tokens |
| 输出规则 | 输出长度与输入长度相同 |
| 记录指标 | 输出吞吐、总吞吐、TTFT、TPOT、端到端耗时 |

进入稳定区间后，长序列输出吞吐保持在约 49–53 tokens/s，TTFT 随输入长度逐步增长。

## 中文与语义验证

- 中文生成返回连贯、连续的正文；
- 对中文输出进行重复性和 token 计数检查；
- 完成约 5K-token 规模的长文本召回检查；
- 使用连续请求验证前一个请求的状态不会污染后一个请求；
- 对主执行路径和 draft 执行路径进行多轮请求检查。

## 图执行与生命周期验证

- 对经过验证的图形状进行捕获和重复回放；
- 将 CPU 专家提交、设备计算、同步和结果合并作为独立生命周期阶段检查；
- 检查多轮图回放中的固定地址工作区和事件所有权；
- 覆盖非规则对齐形状，验证尾部保护和零执行错误；
- 在 TP2 下检查跨 rank 的 CPU 工作归属和最终 collective 边界。

## 推测执行验证

推测路径与目标路径一起验证，而不是作为独立速度测试。检查内容包括：

- draft 到 target 的状态发布；
- verify 与最终处理的顺序；
- 连续多轮推测执行；
- 连续请求之间的 KV 状态连续性；
- 推测执行下的真实输出 token 计数。

## 资源与稳定性验证

- 代表性时间线中 GPU 忙碌率处于高 80% 到低 90% 区间；
- 独立记录 CPU 专家阶段、H2D 和 MCCL 耗时；
- CPU 内存带宽低于流式校准上限；
- 温度和功耗保持在记录范围内，未观察到持续热降频。

## 如何理解最终结果

88.47 tokens/s 是稳定的 C19 四轮聚合结果，背后有完整的 40-case 并发矩阵、83 个长度点、166 次长序列运行、中文与召回检查、连续请求检查、图重放检查和资源探针支持。因此它应被理解为经过正确性与稳定性验证的服务吞吐，而不是一次性峰值。
